# Code-mixed-toxic-comments-Annotation-by-label-studio

## Project Description
This project focuses on annotating toxic and
non-toxic YouTube comments in multilingual
and code-mixed languages.

## Technologies Used
- Python
- Pandas
- NumPy
- Label Studio
- CSV
- GitHub

## Languages
- Odia
- Hindi
- English
- Code-Mixed Languages

## Annotation Categories
1. Toxic
2. Non-toxic
3. Offensive
4. Hate-abusive

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Data Annotation
4. Annotator Agreement
5. Consensus Labelling
6. Dataset Export
7. Data Analysis

## Objective
To develop a labelled dataset that can be
used for multilingual toxicity classification.
